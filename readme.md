# solomon2026

BigWeb と 遊々亭 のトレーディングカード販売価格を横断検索する CLI / REST API / Discord Bot。

[punparin/solomon-api](https://github.com/punparin/solomon-api) にインスパイアされた 2026 年版の再実装です。

## 特徴
- BigWeb は公式 JSON API (`api.bigweb.co.jp`) を利用
- 遊々亭は Cloudflare 対応（Playwright フォールバック付き）
- CLI / FastAPI / Discord Bot の 3 つの入り口
